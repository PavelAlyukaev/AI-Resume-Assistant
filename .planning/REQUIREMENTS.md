# Requirements: AI Resume Assistant

**Defined:** 2026-10-24
**Core Value:** Открыть свой DOCX-файл резюме в приложении и увидеть его текст без потери уже введённых данных.

## v1 Requirements

Требования первого этапа: только чтение DOCX в окне Qt.

### Чтение DOCX

- [ ] **DOCX-01**: Пользователь может открыть `.docx` через диалог выбора файла
- [ ] **DOCX-02**: Абзацы показываются в порядке документа
- [ ] **DOCX-03**: Заголовки показываются как заголовки (по стилю)
- [ ] **DOCX-04**: Маркированные и нумерованные списки показываются с вложенностью
- [ ] **DOCX-05**: Таблицы показываются с строками, пустыми и объединёнными ячейками
- [ ] **DOCX-06**: Кириллица в тексте и путях к файлу читается корректно
- [ ] **DOCX-07**: Изображения пропускаются
- [ ] **DOCX-08**: Гиперссылки и вставки показываются как текст; удалённые исправления не показываются

### Ошибки и безопасность

- [ ] **SAFE-01**: Не-ZIP, повреждённый, зашифрованный файл и старый `.doc` дают понятную ошибку, черновик не меняется
- [ ] **SAFE-02**: Защита от zip-bomb через лимиты распаковки
- [ ] **SAFE-03**: DTD и внешние сущности XML отклоняются
- [ ] **SAFE-04**: Пропущенное содержимое считается и показывается предупреждением, а не теряется молча
- [ ] **SAFE-05**: Текст резюме не попадает в логи и сообщения об ошибках

### Интерфейс

- [ ] **UI-01**: При открытии DOCX с несохранёнными правками приложение спрашивает подтверждение перед заменой
- [ ] **UI-02**: Предпросмотр только для чтения, без записи в SQLite
- [ ] **UI-03**: Строка состояния показывает имя файла и предупреждения

### Тестирование

- [ ] **TEST-01**: Qt Test на синтетических DOCX-фикстурах, включая вредоносные случаи
- [ ] **TEST-02**: Ручной сценарий в окне описан и выполнен

## v2 Requirements

Отложено, в текущий роадмап не входит.

### Расширенный импорт

- **DOCX-V2-01**: Старый формат `.doc`
- **DOCX-V2-02**: DOCX с паролем
- **DOCX-V2-03**: Текстовые поля и колонтитулы как полноценное содержимое (сейчас только предупреждение)

### Перенос в резюме

- **MAP-V2-01**: Автоизвлечение карьерных этапов из DOCX (Sprint 2)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Импорт текстовых PDF | Отдельный этап Sprint 2, другой парсер |
| Импорт изображений и вложений | Не нужно для текста резюме |
| Анонимизация и отправка в API | Sprint 2–3, после чтения документов |
| LLM-провайдеры и AI-интервью | Sprint 3 |
| Анализ профессий и вакансий, экспорт DOCX/PDF | Sprint 4 |
| Веб-интерфейс для импорта DOCX | Пока только окно Qt |
| Запись и экспорт DOCX на этом этапе | Не входит в чтение |
