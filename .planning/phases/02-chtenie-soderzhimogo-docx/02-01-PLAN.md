## Assumptions carried from 02-RESEARCH.md (explicit, with the default chosen)

- **OQ3 (кодировки):** по умолчанию принимаются только объявления `UTF-8` и `UTF-16` (без учёта регистра) и отсутствие объявления; любое другое объявление дает `UnsupportedEncoding`. Альтернатива (отнести к `Corrupt`) отклонена, потому что `Corrupt` означает повреждение. Подтверждение владельца по A10 (правило OPC) ожидается; до подтверждения значение по умолчанию действует.
- **A8 (версия Qt):** поведение токена DTD проверено на Qt 6.11.1 (`[VERIFIED: local probe]`). Минимум в `CMakeLists.txt` (6.7) не проверен; в отчёте SUMMARY указать, что проверка выполнена только на 6.11.1.
- **OQ8 (тексты):** тексты для двух новых кодов пишутся в этом плане, владелец проверит их в фазе 3 вместе с остальными русскими текстами.

## Interface (contract) fixed by this plan

- `readDocxContent(const DocxParts &parts)` принимает байты, не путь (как `readDocxParts`). Возвращает `DocxDocument` или код `DocxError`; частичного результата нет (D-07).
- `DocxDocument::warnings` начинается с копии `parts.warnings` (в этом плане там только отсутствующие части). Дальнейшие предупреждения добавляются в порядке встречи в документе; размер списка равен числу пропусков и приближений (SAFE-04: пропуски закрываются в 02-03, приближения нумерации — в 02-02).
- Текст ошибки XML наружу не возвращается. Внутри слоя `documents` не используется ни один вывод в журнал Qt.
