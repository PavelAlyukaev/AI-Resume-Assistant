Решения и допущения фазы, которые закрываются здесь:

- OQ10 (word/comments.xml): одно предупреждение `OtherSkipped` на часть; содержимое не читается; реализация не ждёт подтверждения владельца, текст проверит владелец в фазе 3.
- Текст лимита `Limit` из фазы 1 общий для распаковки, длины текста и вложенности. Отдельного текста для длины текста не вводится: он описывает оба случая по размеру содержимого. Подтверждение владельца ожидается.
