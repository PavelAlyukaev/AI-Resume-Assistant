## 4. Hooks
- `PreToolUse`: `.claude/hooks/guard_env.py` — best-effort блокировка упоминаний `.env` в параметрах поддерживаемых инструментов.
- `PostToolUse`: `.claude/hooks/check_cpp_format.py` — проверка clang-format изменённых C++ файлов.
- `permissions.deny` дополнительно ограничивает прямые обращения к `.env`.

**Ограничение:** hooks не являются полноценной песочницей ОС; возможны обходные пути через инструменты или команды, которые не покрыты настройкой. Для реальных секретов нужны ограничения доступа и изоляция окружения.
