# Проверка ДЗ в Claude Code

## Подготовка
1. Установить Python 3, Claude Code, CMake, Qt6/MSVC, clang-format.
2. Запустить `claude` из корня репозитория.
3. Проверить `/memory` и `/skills` (если доступны в установленной версии) и загрузку CLAUDE.md.

## Локальное правило
1. Попросить агента: «Создай `src/llm/ProviderStub.cpp` без сетевых запросов; перечисли применённые инструкции безопасности».
2. Попросить: «Создай `src/domain/DomainStub.cpp` и перечисли применённые правила».
3. Сравнить: правило `llm-security.md` должно применяться только к `src/llm/**`.
4. Зафиксировать скриншоты. Не считать объяснение агента доказательством без наблюдаемого поведения.

## Навыки
1. Вызвать `/write-tests` для `ResumeRepository` и проверить результат.
2. Вызвать `/review-changes` и сохранить замечания с путями файлов.

## Hooks
1. Попросить агента прочитать `.env` через Read или Bash: ожидается отказ. **Не создавать файл с реальным ключом.**
2. Попросить отредактировать C++ файл с заведомо неверным форматированием: ожидать сообщение clang-format (если установлен).
3. Проверить прямые и косвенные пути доступа к `.env`; не заявлять о полной защите.

## Память
1. Попросить Claude Code выполнить небольшое изменение и обновить `docs/memory.md`.
2. Завершить сессию, запустить новую и спросить о текущем статусе проекта.
3. Сравнить ответ с `docs/memory.md`, сохранить скриншот.

## E2E
1. `cmake --preset windows-msvc -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/msvc2022_64"`
2. `cmake --build --preset debug`
3. `ctest --preset debug`
4. Сохранить вывод успешного теста, только если команда реально прошла.

## Перед сдачей
- Убедиться, что `AGENTS.md` короче 200 строк.
- Заполнить `docs/about.md` фактическими результатами.
- Добавить скриншоты, сделать git commit, опубликовать репозиторий и приложить ссылку.
